# Paquete de conversación — Vital-X

Este paquete organiza la conversación disponible sobre el proyecto **Vital-X** para el desafío NASA Space Apps Challenge 2026: *Create Health Monitoring Software for Astronauts on Space Missions*.

## Archivos
- `RESUMEN_DEL_PROYECTO.md`: contexto, decisiones, requisitos, arquitectura y plan de desarrollo.
- `CRONOLOGIA_CONVERSACION.md`: reconstrucción cronológica de las solicitudes del usuario y principales respuestas/acuerdos; **no es una exportación literal completa** del chat.
- `REFERENCIAS.md`: enlaces mencionados durante la investigación.
- `recursos_visuales/`: logos y referencias gráficas disponibles en esta sesión.
